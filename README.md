# Multi-Step Form Validation

A responsive and interactive multi-step form built with HTML, CSS, and JavaScript. The project focuses on validating user input and providing clear feedback to ensure accurate form submissions.

## 🌐 Live Demo

[View Live Demo](YOUR_LIVE_DEMO_URL)

## ✨ Features

- Responsive design for different screen sizes.
- Client-side form validation using JavaScript.
- Required field validation.
- Input format validation with clear error messages.
- Conditional navigation between form steps.
- Prevents users from proceeding with invalid or incomplete data.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
